# transgender.life 隐私政策

**最后更新：2026年9月**

transgender.life（以下简称“本网站”）尊重您的隐私，并致力于以尽可能少的数据处理提供网站服务。

本隐私政策说明本网站目前如何处理与网站访问及用户主动提交的信息有关的数据。

本网站按照《欧盟通用数据保护条例》（GDPR）的透明度、目的限制、数据最小化、存储限制及安全等原则制定本政策，并在适用范围内参考英国 GDPR 等相关数据保护法律的要求。

## 1. 数据控制者

本网站由个人独立运营。

就您直接向本网站提交的个人数据而言，本网站运营者通常作为数据控制者（Data Controller）负责决定相关数据的处理目的和方式。

如您需要就个人数据处理事项与运营者联系，可以通过网站提供的 Microsoft Forms 联系方式提交请求。

## 2. 本网站目前不提供账户系统

transgender.life 目前：

* 不要求用户注册账户；
* 不建立用户个人账户；
* 不要求用户提供姓名、电话号码或电子邮件地址才能浏览网站；
* 不提供用户投稿功能；
* 不提供公开评论功能；
* 不提供私信功能；
* 不建立用户个人资料档案。

因此，您通常可以在不主动向本网站提供个人资料的情况下浏览网站。

## 3. 网站访问产生的技术数据

由于本网站托管于 Cloudflare Pages，用户访问网站时，请求可能经过 Cloudflare 的网络基础设施。

作为提供网络托管、安全、内容传输及相关基础设施服务的一部分，Cloudflare 可能处理与网络请求有关的技术数据，例如 IP 地址、请求及网络活动相关的元数据等。

这些数据主要由基础设施服务用于提供、维护、保护和改善相关网络服务，例如安全防护、故障排查和防止滥用。

Cloudflare 对其自身数据处理另有隐私政策。有关 Cloudflare 如何处理数据，请参阅其官方隐私政策。

本网站运营者不会利用这些技术数据建立用户个人档案，也不会主动要求用户提供上述技术数据。

## 4. 联系表单

本网站可能提供 Microsoft Forms 作为联系运营者的渠道。

当您主动提交联系表单时，本网站可能获得以下信息：

* 您填写的网名；
* 您主动提供的电子邮件地址（可选）；
* 您填写的留言内容；
* 表单服务运行过程中可能产生的相关技术信息。

电子邮件地址不是提交留言的必要条件。除非您主动填写，否则本网站不会通过该表单要求您提供电子邮件地址。

表单内容仅用于：

* 回复您的联系或询问；
* 处理您提出的意见、纠错或建议；
* 了解并改进网站内容；
* 在必要时处理与网站运营有关的问题。

您提交的留言**不会被公开展示在 transgender.life 上**。

请不要在联系表单中提交不必要的敏感个人资料，例如身份证件、密码、财务账户信息或与您联系目的无关的医疗资料。

Microsoft Forms 是由 Microsoft 提供的第三方服务。Microsoft 会按照其适用的隐私政策及服务条款处理相关数据。Microsoft 已说明 Microsoft Forms 满足 GDPR 相关合规要求，并提供相关数据主体请求机制。

## 5. 数据处理的法律依据

对于您主动通过联系表单提交的信息，本网站可能基于以下法律依据处理数据：

**履行您的请求或采取相关步骤。**

例如，当您主动提供联系方式并要求运营者回复时，处理这些信息是为了回应您的请求。

**合法利益（Legitimate Interests）。**

在必要且适当的情况下，本网站可能基于运营、维护、安全、防止滥用以及维护网站正常运行等合法利益处理有限的相关信息，同时考虑数据主体的权利和利益。

**法律义务。**

如果法律要求本网站保存、提供或处理某些信息，本网站可能根据相应法律义务进行处理。

如果未来采用需要取得同意的数据处理方式，例如某些非必要 Cookie、广告技术或其他追踪技术，本网站将在适用情况下依法取得相应同意。

## 6. 数据最小化

本网站遵循数据最小化原则，只处理实现特定目的所必要的数据。

目前网站没有必要通过注册账户收集个人资料，因此不会因为提供基本网站浏览功能而要求用户创建账户或提交个人信息。

## 7. 数据保存期限

联系表单提交的信息不会被无限期保存。

本网站运营者会根据实际运营需要、法律义务及处理目的保存相关信息，并在不再需要时删除或匿名化处理。

由于联系表单由 Microsoft Forms 提供，相关数据还可能受到 Microsoft 对其服务数据的保存机制及政策约束。

如果您希望删除自己通过联系表单提交的信息，可以通过网站提供的联系方式提出请求。

## 8. 数据共享及第三方服务

本网站目前不会出售、出租用户个人数据，也不会将用户提交的联系资料用于与本网站无关的商业营销。

目前与网站运行有关的主要第三方服务包括：

### Cloudflare

网站托管及网络基础设施由 Cloudflare Pages 提供。

Cloudflare 可能处理与访问请求有关的技术数据和网络元数据。Cloudflare 对其相关数据处理具有独立的隐私政策。

### Microsoft Forms

联系表单由 Microsoft Forms 提供。

用户主动提交的网名、可选电子邮件地址及留言内容会通过 Microsoft 的服务传输和处理。

Microsoft Forms 的数据安全及隐私信息可参见 Microsoft 的官方说明。

如果未来增加其他第三方服务，本隐私政策将相应更新。

## 9. 国际数据传输

由于本网站使用的第三方基础设施和服务可能在不同国家或地区运营，相关数据可能在用户所在国家或地区以外进行处理。

对于适用 GDPR 的数据传输，本网站将根据适用法律采用相应的数据保护机制，例如欧盟委员会的充分性决定、标准合同条款（SCC）或其他法律允许的传输机制。

第三方服务提供商可能拥有自己的国际数据处理安排，本政策不会取代这些服务商各自适用的隐私政策。

## 10. Cookie 和类似技术

目前 transgender.life 不以建立用户账户或个人画像为目的设置非必要 Cookie。

如果未来网站加入：

* 网站分析工具；
* 广告；
* 个性化内容；
* 第三方追踪技术；
* 其他非必要 Cookie；

本网站将在适用法律要求的情况下更新 Cookie 政策，并在必要时在使用相关技术前取得用户同意。

## 11. 广告

目前本网站可能尚未启用广告服务。

如果未来启用广告，相关广告提供商可能根据其自身技术和隐私政策处理包括设备信息、IP 地址、Cookie 或其他在线标识符在内的数据。

在启用涉及个人数据处理或非必要追踪技术的广告服务之前，本网站将根据适用法律更新本隐私政策及 Cookie 相关说明，并在需要时提供相应的同意或拒绝机制。

## 12. 打赏

未来本网站可能提供第三方打赏服务。

如果启用打赏，支付过程通常会由相应的第三方支付或打赏平台处理，而不是由 transgender.life 自行处理完整的支付卡信息。

具体数据处理方式取决于所采用的第三方服务，并会在相关服务启用时更新本隐私政策。

## 13. 您的数据保护权利

在 GDPR 适用的情况下，您可能享有以下权利：

* 知情权；
* 访问个人数据的权利；
* 更正不准确个人数据的权利；
* 删除个人数据的权利；
* 限制处理的权利；
* 数据可携带权；
* 在特定情况下反对处理的权利；
* 在处理基于同意的情况下撤回同意的权利；
* 不受仅基于自动化处理并产生法律或类似重大影响的决定约束的权利。

这些权利并非在所有情况下都绝对适用，具体是否可以行使以及适用哪些例外情况，应按照适用的数据保护法律判断。

## 14. 如何提出数据请求

如果您希望：

* 查询我们是否持有与您有关的个人数据；
* 请求更正数据；
* 请求删除数据；
* 请求限制或反对特定的数据处理；
* 对本网站的数据处理提出其他问题；

可以通过本网站提供的 Microsoft Forms 联系运营者。

为了防止未经授权的人员获取或删除他人的信息，在处理某些请求前，运营者可能需要采取合理方式确认请求人的身份。

## 15. 投诉权

如果您认为自己的个人数据保护权利受到侵犯，您可以首先通过本网站提供的联系方式与运营者联系。

您也有权根据适用法律向具有管辖权的数据保护监管机构提出投诉。

如果 GDPR 或英国 GDPR 适用于您的情况，您可以向相应的数据保护监管机构寻求帮助。

## 16. 儿童隐私

本网站设置最低年龄限制为13岁。

本网站不以收集儿童个人资料为目的，也不提供需要建立账户的服务。

如果运营者得知未满13岁的儿童向本网站主动提交了个人资料，将在适用法律要求的范围内采取合理措施删除相关信息。

## 17. 数据安全

本网站会采取与其规模、性质和风险相称的合理技术和组织措施，以保护个人数据免受未经授权的访问、丢失、滥用或非法处理。

由于互联网传输和电子存储无法保证绝对安全，本网站无法保证信息在所有情况下均不存在安全风险。

## 18. 本政策的更新

随着网站功能、第三方服务或适用法律发生变化，本隐私政策可能进行更新。

更新后的版本将在本页面发布，并注明最后更新时间。

如果未来加入广告、网站分析、Cookie、打赏或其他涉及个人数据的新功能，本政策将根据实际的数据处理方式进行更新。
